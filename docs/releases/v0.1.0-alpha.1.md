# MachineryPro AI v0.1.0-alpha.1

## Release Status

**Engineering Foundation Alpha**

This is the first public alpha engineering release of MachineryPro AI.

It establishes the verified deterministic machining engineering foundation and the first process-specific deterministic core.

## Included

### Repository Foundation

- Standalone MachineryPro AI repository
- Preserved original Machinery AI engineering history
- Integrated GitHub repository bootstrap history
- Independent product identity and repository history

### Stage 3A — Deterministic Machining Math Foundation

Verified commit:

`e2ebefb` — `feat: establish deterministic machining math foundation`

Stage 3A provides the deterministic machining calculation foundation, including:

- engineering formulas
- explicit validation
- engineering rules
- exception handling
- unit-tested deterministic behavior
- technical documentation

### Stage 3B — Deterministic Turning Engineering Core

Verified commit:

`06338db` — `feat: establish deterministic turning core`

Stage 3B provides the first process-specific deterministic machining core, including:

- turning calculations
- turning engineering rules
- deterministic validation
- turning-specific tests
- technical documentation

## Engineering Principle

> Deterministic engineering calculations are authoritative.  
> AI acts as an explainable advisory layer and must not silently override validated engineering results.

AI availability is not required for authoritative machining calculations.

## Validation

The release baseline has been validated against:

- Stage 3A formula tests
- Stage 3A engineering rule tests
- Stage 3B turning tests
- Stage 3B turning rule tests
- git diff integrity checks

The repository migration preserves both the original engineering history and the new MachineryPro AI GitHub bootstrap history.

## Product Status

This release is an **alpha engineering foundation release**.

It is not a production-ready or feature-complete commercial release.

## Not Included Yet

The following areas remain future product work and should not be interpreted as implemented in this release:

- STEP / CAD manufacturing feature recognition
- automated DFM workflow
- full CAPP / process planning
- production CAM generation
- CNC connectivity
- shop-floor monitoring
- APS / production scheduling
- full costing and quotation workflow
- closed-loop learning
- predictive tool wear
- chatter prediction
- autonomous machining decisions

## Known Limitations

- The current public release primarily represents the deterministic engineering foundation.
- Broader product modules remain under staged development.
- AI functionality is not authoritative for engineering calculations.
- A Windows-specific smoke-test/source-material environment anomaly has been observed during migration validation and is not part of the deterministic machining engineering test gate.

## Development Direction

The product will continue through staged development:

**Foundation → Engineering MVP → Engineering Intelligence → Connected Manufacturing → Advanced Intelligence → Process Expansion**
